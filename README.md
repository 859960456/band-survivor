## 游戏简介

### 世界观
**暗渊行者**是一个黑暗奇幻风格的肉鸽（Roguelike）生存游戏。你是一位被诅咒的探险者，被困在名为「暗渊」的无限地牢中。每层地牢由随机生成的房间和走廊组成，隐藏着怪物、宝藏、陷阱和未知事件。你必须不断向下探索，收集装备、提升实力，争取活着离开——或者，倒在下一层。

### 核心玩法
- **走格子探索**：手指滑动操作角色在网格地图上移动，撞上怪物进入战斗，触碰物品拾取效果
- **回合制战斗**：普攻、技能、药水、连击系统，战斗节奏适合手环操作
- **肉鸽三选一**：升级时从三个随机强化中选择一个，构建你的 Build
- **装备系统**：35 种武器、32 种防具，每种都有独特效果（触发、叠层、代价、套装协同）
- **状态与元素**：中毒、灼烧、冰冻、感电、流血 — 火毒爆炸，冰电麻痹
- **职业与转职**：战士、游侠、法师，等级 8 可转职
- **遗物与天赋**：27 个遗物、34 项天赋，支持多种流派
- **召唤系统**：遗物召唤史莱姆、影分身、喵星人等召唤物挡刀
- **附魔与宝石**：商店可附魔武器、镶嵌宝石，进一步强化
- **技能书**：6 种技能可切换（芜湖起飞、芭比Q、奥利给斩……）
- **每日任务与成就**：每日签到、每日任务、29 个成就（含热梗成就）
- **无尽模式/挑战模式/NG+轮回**：多周目持续挑战

### 设计原则
本游戏遵循**装备设计五原则**（详见 `docs/DESIGN_PRINCIPLES.md`）：
1. **正交性**：装备与多个系统互动
2. **构建定义**：一件装备可围绕组 Build
3. **取舍**：强效果伴随代价（Push-Pull）
4. **触发与协同**：效果有触发条件/叠层/联动
5. **怪物也有趣**：每个怪物有独特机制

### 操作说明
- **首页**：选择难度、职业、模式，开始冒险
- **地牢**：手指滑动屏幕移动角色，撞怪进战斗，碰物品拾取
- **战斗**：点「攻击」普攻，点「技能」释放技能，点「药水」回血
- **商店**：购买/强化装备，打造/赌博，附魔/镶嵌宝石
- **背包**：查看装备属性，分解装备获得材料

### 构建与运行

```bash
# 调试构建
npm run build

# 正式发布
npm run release

# 真机运行
npm run start
```

生成的 RPK 在 `dist/` 目录。
