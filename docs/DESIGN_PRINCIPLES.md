# 暗渊行者 · 设计铁律（后续新增内容必须遵守）

> 2026-08-23 由用户明确要求记录：以后做装备、技能、天赋等都必须按此设计，不能只加白板数值。

## 1. 禁止“白板数值”
任何新增武器/防具/遗物/天赋/技能，必须有**独特机制**，至少满足以下之一：
- 改变玩法/技能形态
- 触发型效果（概率/条件/叠层）
- 协同联动（与状态、流派、其他装备互动）
- 代价取舍（Push-Pull：强效果带负面）

## 2. 装备设计五原则
1. **正交性**：与多个系统互动，不单用途。
2. **构建定义**：一件装备能让玩家围绕它组 Build（流派标签）。
3. **取舍**：强效果伴随代价。
4. **触发与协同**：效果有触发条件/叠层/联动。
5. **怪物也有趣**：新怪物要有挑衅性机制。

## 3. 参考来源
- Hades：武器/祝福改变打法
- Slay the Spire：遗物/卡牌构建与代价
- Roguelike Item Orthogonality：多交互、非单用途
- Eight Rules of Roguelike Design：强必有代价

## 4. 数据结构约定
装备对象至少包含：
```js
{
  name: '毒鸡汤', atk: 8,
  type: '法杖',            // 武器类型 → 技能形态
  tags: ['毒'],           // 流派标签 → 套装/协同
  bonus: { ... },         // 常驻增益
  penalty: { ... },       // 常驻代价
  proc: { ... }           // 触发型效果
}
```

## 5. 验收
新增内容若只有 `atk/def/value` 而无机制，视为未完成。
