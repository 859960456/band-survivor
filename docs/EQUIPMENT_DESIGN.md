# 暗渊行者 · 装备/武器系统重设计（基于成功肉鸽设计研究）

## 一、核心问题
当前新增武器/防具只加 `atk/def`，是“换皮数值”，违背肉鸽核心：**装备应改变玩法、产生组合与取舍**。

## 二、从成功游戏提炼的设计原则

### 1. 正交性（Orthogonality）
> 装备不应只有一个用途，而应与多个系统发生交互。
- 例：Hades 的 Zeus 雷击不只是伤害，还会与“雷击触发次数”“范围”互动。
- 落到本游戏：一把武器不只加攻击，还改变**技能形态**、**触发状态**、**连击逻辑**、**经济收益**。

### 2. 构建定义（Build-defining）
> 一件装备能让玩家围绕它组 Build。
- 例：Slay the Spire 的“毒牌组”“力量牌组”“护甲牌组”。
- 落到本游戏：装备应带**流派标签**：毒系、火系、冰系、暴击系、连击系、防御系、金币系、召唤系。

### 3. 取舍（Push-Pull）
> 强效果往往伴随代价，避免无脑强。
- 例：Slay the Spire 的诅咒遗物、Hades 的逆天锤子也有副作用。
- 落到本游戏：加“负面词条”，如高攻低血、高金币低闪避、高连击低经验。

### 4. 触发与协同（Proc & Synergy）
> 效果最好有“触发条件”和“联动”，而不是常驻数值。
- 例：Hades 的 Doom（延迟伤害）、Slay the Spire 的“中毒叠加”。
- 落到本游戏：引入 **状态叠层**（毒/火/冰/电/流血），武器攻击概率叠层，天赋/遗物放大叠层收益。

### 5. 怪物也要有趣
> 敌人不应该是木桩，要有挑衅性能力（Eight Rules）。
- 落到本游戏：新怪物加入“偷技能、召唤、分裂、狂暴、反伤”等机制，与装备系统互动。

## 三、重设计方案

### A. 武器 = 改变“打法”
每种武器类型决定主动技能的**形态**，而非仅名字：

| 类型 | 技能形态 | 代表武器 |
|---|---|---|
| 剑 | 单体高倍率 | 黄金精神之剑、奥利给巨剑 |
| 刀 | 单体+流血 | 韭菜盒子、绝绝子 |
| 锤 | 范围伤害 | 摸鱼铲、老板画的饼、破防锤 |
| 法杖 | 元素/状态 | 毒鸡汤、芜湖起飞器、我不李姐 |
| 弓 | 穿透后排 | 退退退 |
| 拳 | 连击强化 | 卷王键盘、六六六、有无搞错 |
| 伞 | 防御/格挡 | 躺平枕头、绷不住了 |

### B. 武器独特效果（触发型，非纯数值）
| 武器 | 独特机制 |
|---|---|
| 毒鸡汤 | 攻击 30% 给怪叠 1 层毒（每层回合结束扣血） |
| 摸鱼铲 | 每场战斗结束获得额外经验（摸鱼反而涨经验） |
| 卷王键盘 | 连击 +1，但经验 -10%（内卷的代价） |
| 躺平枕头 | 生命低于 50% 时格挡 +20%，但攻击 -2 |
| 老板画的饼 | 击杀获得金币 +50%，但攻击 -2（画饼不加攻） |
| 黄金精神之剑 | 暴击时追加“黄金精神”真实伤害 |
| 韭菜盒子 | 吸血 +1，但被偷金币概率翻倍 |
| 芜湖起飞器 | 技能伤害 +50%，但技能 CD +1（起飞要蓄力） |
| 六六六 | 攻击概率连击 +2 |
| 栓Q | 攻击概率偷取怪物金币 |
| 绝绝子 | 暴击伤害 +50% |
| 我不李姐 | 受击概率获得护盾 |
| 破防锤 | 攻击无视 30% 防御 |
| 绷不住了 | 每攻击一次回复 2 血 |
| 退退退 | 闪避 +10%，但攻击 -1 |
| 拿来吧你 | 拾取金币翻倍 |
| 奥利给巨剑 | 攻击很高但攻速慢（每 2 回合才能攻击？简化：连击 -1） |
| 皮皮虾我们走 | 移动不触发怪物回合的概率 +20% |
| 好家伙 | 每次攻击有 10% 造成 2 倍伤害 |
| 有无搞错 | 暴击率 +5%，但暴击伤害 -30% |

### D. 流派标签与套装
- 每件武器/防具有 1~2 个标签：`毒/火/冰/电/暴击/连击/防御/金币/召唤/摸鱼/内卷/躺平`。
- 2 件同标签：获得小协同；3 件同标签：获得流派大招。
- 例：
  - 毒系 2 件：毒叠层上限 +3
  - 毒系 3 件：毒叠满时自动爆炸
  - 金币系 2 件：商店打 8 折
  - 金币系 3 件：每层开始获得金币

### E. 负面/代价设计（Push-Pull）
- 高收益装备必带代价，让玩家在“数值 vs 机制”之间选择。
- 代价类型：攻击-、生命-、闪避-、经验-、金币-、连击-、CD+、赌博费+。

## 四、实施路线（确认后执行）

1. **数据结构**：`game-data.js` 的武器/防具增加：
   ```js
   { name: '毒鸡汤', atk: 8, type: '法杖', tags: ['毒'], skill: 'poison_bolt',
     bonus: { burnChance: 0.03 }, penalty: { atk: -1 }, proc: { poison: { chance: 0.3, stacks: 1 } } }
   ```
2. **装备应用/移除**：`_equipRolled` / `_pickItem` / `buyItem` / `_dropWeapon` 换装时结算 bonus + penalty + tags。
3. **武器类型→技能形态**：`_skillMult` / `doSkill` 按 type 选择技能形态。
4. **状态叠层系统**：毒/火/冰/电/流血实现“叠层 + 回合结算 + 联动”。
5. **套装系统**：统计已装备武器+防具的 tags，激活 2/3 件效果。
6. **新怪物机制**：偷技能、召唤、分裂、狂暴叠加等。

---

## 五、平衡原则
- 每个武器/防具的“总价值”用公式计算：`攻击×权重 + 机制价值 - 代价`，尽量拉平。
- 机制价值：触发型按期望值折算，例如 30% 概率 3 层毒 ≈ 攻击 +3。
- 套装效果不叠加到单件价值里，作为额外奖励，避免单件超模。

## 六、待确认
1. 这个方向 OK 吗？是否按“武器类型→技能形态 + 独特触发 + 代价”实施？
2. 状态叠层系统（毒/火/冰/电/流血）要不要现在做？它是很多效果的基础。
3. 套装系统是否本轮做，还是先做单件效果？
4. 负面代价是否可接受？（有些玩家不喜欢被惩罚，但肉鸽传统是“强必有代价”）
