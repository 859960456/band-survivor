# 第四轮 · Vela 滚动组件根治（2026-08-23，用户提供海龟汤项目参考）

## 根因
Vela 快应用 `<scroll>` 正确写法必须满足：
1. `scroll-y="{{true}}"`（**表达式绑定**，不能写 `scroll-y="true"` 字符串字面量）；
2. 滚动区内**只能有一个子节点**；
3. 该子节点必须是 `position: absolute; width: ...; flex-direction: column;` 的容器；
4. 列表（`for`）和所有内容都放在这个容器里，整页上下滚动。

参考：`D:\aiotide\turtlesoup\src\pages\about\about.ux`、`play.ux` 的 `.bodyInner` 写法。

## 修复清单
- **商店**：整页单 scroll + 内层 `position:absolute; flex-direction:column`；商品 + 按钮统一滚动。
- **背包**：同上。
- **首页**：`home-scroll` 补 `.home-scroll` 高度样式；`home-content` 加 `position:absolute`。
- **天赋/图鉴/成就**：三个 `shop-scroll` 统一改为单内层容器 + `scroll-y="{{true}}"` + 内联高度 300px。
- **战斗**：`battle-scroll` 加内层容器。
- **底部菜单**：`menu-scroll` 从“多子节点 + scroll 自带 flex”改为“单内层容器”，去掉 scroll 自身的 flex 属性。

## 验证
- `npm run build` 成功，仅剩工具链自身弃用提示。
- 全项目 8 个 `<scroll>` 全部为 `scroll-y="{{true}}"`，旧的 `scroll-y="true"` 已清零。
- `<scroll>` 开合标签 8/8 配对。
